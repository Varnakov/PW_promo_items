# Выделить чекбоксы (Perfect World)

Userscript для страницы передачи предметов на [pwonline.ru](https://pwonline.ru/promo_items.php).

## Установка

### 1. Tampermonkey

Скрипт работает через расширение **Tampermonkey**. Если его нет — установите:

[Tampermonkey в Chrome Web Store](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)

### 2. Установка скрипта

Откройте ссылку ниже в браузере с Tampermonkey — расширение предложит установить скрипт:

**https://raw.githubusercontent.com/Varnakov/PW_promo_items/main/pw-select-checkboxes.user.js**

Нажмите **Установить**.

### 3. Готово

Откройте или обновите страницу:

**https://pwonline.ru/promo_items.php**

---
## Обновления

Скрипт обновляется автоматически через Tampermonkey.

Проверить вручную: **Tampermonkey → Панель управления → скрипт → «Проверить обновления»**.

---

## Установка вручную (если ссылка не сработала)

1. На странице https://pwonline.ru/promo_items.php нажмите на иконку Tampermonkey → **«Создать новый скрипт»**.
2. Скопируйте всё содержимое файла [pw-select-checkboxes.user.js](./pw-select-checkboxes.user.js) и вставьте в редактор.
3. **Файл → Сохранить** (Ctrl+S).
4. Обновите страницу pwonline.ru.

---

## Что делает скрипт

1. **Снятие лимита** — можно вручную выделить более 6 предметов (сайт по умолчанию ограничивает выбор шестью).
2. **«Выделить все предметы → Передать»** — ставит галочки на всех чекбоксах и прокручивает страницу к кнопке «Передать».
3. **«Выделить 6 предметов → Передать»** — выделяет первые 6 предметов и прокручивает к кнопке «Передать».
4. **Сервер** — по умолчанию выбирается **«Цефей»** (если он есть в списке).
5. **Персонаж** — автоматически выбирается персонаж с **наибольшим уровнем**; при одинаковом уровне — **первый по алфавиту**.

Если сервер или персонажа сменить вручную, скрипт больше не будет их переопределять до перезагрузки страницы.
